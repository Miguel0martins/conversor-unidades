# Conversor de Unidades

Projeto desenvolvido em Java aplicando os conceitos do curso
"Java: criando a sua primeira aplicação" da Alura.

## 🧠 O que o projeto faz

Programa de console com menu interativo que realiza 5 tipos de conversão:

- Cálculo de IMC (peso/altura)
- Celsius → Fahrenheit
- Km → Milhas
- Real → Dólar
- Quilograma → Libras

## 💻 Conceitos aplicados

- Tipos primitivos (`int`, `double`)
- Leitura de dados com `Scanner`
- Estruturas condicionais (`if/else`)
- Estrutura de repetição (`while`)
- Formatação de números com `String.format`

## ▶️ Como executar

\```bash
javac ConversorUnidades.java
java ConversorUnidades
\```
